Safety boundaries

  • The extension does not request cookie, history, or saved-password permissions.
  • Only the registered BrowseWeave helper can start local setup; websites and content scripts cannot call it.
  • Ordinary AI commands cannot fill password, one-time-code, or payment-card fields.
  • Local credential handoff values stay inside the extension; optional remote mode is exact-origin, one-use, and user-granted.
  • Sensitive actions wait for an approval signed by this browser profile.
  • CAPTCHA, passkey, security-key, 403, and 429 screens require direct user action.
